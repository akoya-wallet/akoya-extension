## Colours

| Token | Hex |
|---|---|
| Background (ink) | `#11172A` |
| Wordmark | `#11182A` |
| Pearl | `#FAFBFE` |
| Crescent gradient | `#FDFCFF` → `#C5C1FD` |

The near-white pearl has low contrast on white — use the **ink** variants on light backgrounds.
Never scale a horizontal lockup down to an app icon.
